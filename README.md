## 📸 About the Project

**Maa Kali Videography & Photography** is a responsive portfolio website
designed to showcase professional photography and videography services.

The website provides visitors with an easy way to:

- 🎬 Watch the featured video/showreel
- 📷 Explore photography and videography work
- 💍 Discover wedding and event services
- ✈️ Explore tour and travel coverage
- 🎞️ Learn about video editing services
- 💬 Contact directly through WhatsApp
- 📞 Call directly from mobile
- 📧 Send an email
- 📸 Visit Instagram

---

## ✨ Features

### 🎬 Video Showreel

The website includes a dedicated video playback section with:

- Custom play button
- HTML5 video player
- Native playback controls
- Responsive video layout
- Mobile-friendly playback
- Poster image support
- `playsinline` support for mobile devices

Example:

```html
<video controls playsinline preload="metadata">
  <source src="assets/showreel.mp4" type="video/mp4">
</video>
````
